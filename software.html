Open-source Software

SZR+

A QGIS plugin for machine-learning landslide susceptibility mapping (Random Forest, Logistic Regression, SVM). I extended the original vector-analysis code with raster-analysis capability and built a simplified interface that also works for teaching. SZR+ v2, based on SZ-plugin v2.0, adds more models and spatial, temporal and space-time validation, and is in development.

QGISPythonMachine LearningLandslide Susceptibility

SZR+ for ArcGIS

The same landslide susceptibility approach as an ArcGIS Pro Python Toolbox, for users who work in ArcGIS rather than QGIS.

ArcGIS ProPython Toolbox

DCASCADE_Qpy

A QGIS interface for the DCASCADE-py sediment cascade model, so the model can be run without coding. I built the plugin and its QGIS-native tools, and added stored-sediment outputs. The modeling core is DCASCADE-py by M. Tangi et al.
